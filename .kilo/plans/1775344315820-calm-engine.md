# Hero Section Analysis & Redesign Plan

## Current Implementation Analysis

### Image Loading Issue

**Location**: `components/sections/Hero.tsx` (lines 30-36)

**Why it's slow**:
1. **Large file size**: `hero-cargo.jpg` is **714KB** - far too large for a hero background
2. **No Next.js image optimization**: The `next/image` component is used with `fill`, but:
   - No `sizes` prop specified - Next.js can't generate responsive srcsets
   - No `quality` prop (defaults to 75)
   - No `placeholder` - no blur-up effect while loading
   - Not using `priority` on the correct element (it's set but the image is still slow)
3. **Static file in public folder**: Served as-is without optimization

**Current code**:
```tsx
<Image
  src={imageSrc}  // "/images/stock/hero-cargo.jpg" - 714KB
  alt="Cargo trucks and shipping containers for logistics"
  fill
  className="object-cover"
  priority  // Set, but doesn't help with the root issue
/>
```

### Wave Design Issue

**Location**: `components/sections/Hero.tsx` (lines 122-127)

**Current implementation**: Static SVG with hardcoded path:
```tsx
<svg viewBox="0 0 1440 120" ...>
  <path d="M0 120L60 110C120 100..." fill="#EDF3FA" />
</svg>
```

**Problems**:
1. Static - no animation or movement
2. Single color - can't adapt to theme colors
3. Hardcoded path - not easily customizable
4. Hidden on mobile (`hidden md:block`) - inconsistent experience
5. Simple curve - looks dated

## Redesign Solutions

### 1. Fix Slow Image Loading

**Options**:
- A) **Use next/image properly**: Add `sizes`, `quality`, and convert to import
- B) **Replace with CSS gradient/pattern**: For better performance
- C) **Use a placeholder background**: Color + pattern while image loads
- D) **Compress the image**: Use WebP/AVIF with proper sizing

### 2. Redesign Wave

**Options**:
- A) **Animated CSS wave** - Subtle movement, modern look
- B) **CSS-only geometric separator** - No SVG, more reliable
- C) **Gradient fade** - Clean, modern, lightweight
- D) **Layered waves** - More depth and visual interest

## Implementation Plan (Confirmed)

### 1. Fix Slow Image Loading: Next.js Image + Compression

- Convert hero-cargo.jpg to WebP/AVIF format (aim for <150KB)
- Add proper `sizes` prop to the Image component: `sizes="100vw"`
- Add `quality={80}` (lower than default 75, but with better format)
- Add `placeholder="blur"` with blurDataURL for progressive loading
- Consider using `priority` is already set - that's correct

### 2. Redesign Wave: Modern Gradient Fade

- Replace static SVG wave with CSS gradient fade
- Use `bg-gradient-to-b` from navy to white/light-gray
- Remove SVG wave code entirely
- Make visible on all devices (remove `hidden md:block`)
